## Build with XeLaTeX

The repository uses XeLaTeX because `main.tex` loads `fontspec` and uses Arial.
A TeX distribution containing XeLaTeX and BibTeX is required, and Arial must be
installed on the system.

Run the following commands from the repository root:

```sh
xelatex -interaction=nonstopmode -halt-on-error main.tex
bibtex main
xelatex -interaction=nonstopmode -halt-on-error main.tex
xelatex -interaction=nonstopmode -halt-on-error main.tex
```

The resulting document is `main.pdf`. Files such as `main.aux`, `main.log`,
`main.toc`, and `main.lof` are generated by LaTeX and should not be edited
manually.

## Repository use

- Thesis metadata is defined near the beginning of [main.tex](main.tex).
- Thesis text is stored in `chapter/` and included from `main.tex`.
- Bibliographic entries are stored in [masterarbeit.bib](masterarbeit.bib).
- Images used by the thesis are stored in `resources/images/`.
- Scientific and agent rules are defined in [AGENTS.md](AGENTS.md).

The existing chapter files still contain demonstration content from the original
template. The project builds successfully with XeLaTeX and currently produces
non-fatal warnings about layout boxes, glossary output, and `\include` placement.
