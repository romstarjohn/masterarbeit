# AI-usage documentation

This directory documents material use of AI during the thesis.

Authorized entries are recorded in [ai-usage-log.md](ai-usage-log.md). Each entry
identifies the date, tool or model when known, purpose, retained output, human
verification, and affected files or thesis sections.

AI output is not scientific evidence. Claims, citations, quotations, data, and
calculations produced with AI must be checked against their original sources.
